Setup & Reference

once-per-night checklist · focus · math

Once Per Night — Camera Prep

  • Fresh battery in, spares in a warm pocket (cold halves LP-E5 life)
  • Card formatted in camera
  • Quality: RAW · Picture Style irrelevant to RAW
  • WB: K → 4000 (never Auto — it drifts frame to frame)
  • C.Fn II-1 Long-exposure NR: per scenario above
  • C.Fn II-2 High ISO NR: 0 (Off)
  • Auto power off: Off · Review time: Off
  • LCD brightness: minimum (preserves night vision)
  • Remove any UV/protection filter (star flares, dew rings)
  • Lens hood on; hand-warmer rubber-banded to barrel if humid
  • Tripod locked, strap removed or wrapped (wind shake)
  • Intervalometer plugged into the 2.5mm remote port (left side)

Focus — Do This Every Time

  1. Pull the Tokina focus ring back toward the camera — that's its manual-focus clutch. Set roughly on the ∞ mark.
  2. Press the Live View button; aim at the brightest star or planet.
  3. Zoom to 10× with the magnify button.
  4. Rock the ring until the star is the smallest possible point — the Tokina focuses past infinity, so never trust the hard stop.
  5. Tape the ring. Recheck after ~1 h (glass shifts as it cools).

Histogram target for sky frames: main hump ¼–⅓ from the left edge. Hugging the left = lift ISO; past halfway = skyglow is winning, shorten or stop down.

Afterwards — Umbra Noctis

Copy the night into one folder, darks in a subfolder. CR2 files load directly (one-time setup: pip install 'umbra-noctis[dslr]').

Star trails (lighten blend, gaps auto-bridged, hot pixels auto-repaired; add --fade 0.01 for comet tails, --foreground base.tif for a noise-free landscape):

umbra trails ./night -o trails.jpg --darks ./darks

Meteor nights — the scanner culls hundreds of frames to the few with streaks (satellites auto-rejected), then --align composites every meteor onto one fixed sky:

umbra meteor-scan ./night --copy-to keepers/
umbra trails ./keepers -o meteors.tif --align

Never run plain umbra stack on trail frames — it aligns the stars, which erases the trails. Full manual: umbra guide.
